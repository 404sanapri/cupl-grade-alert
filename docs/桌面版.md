# 桌面版 exe（打开就监测，关掉就停）

不想装 Python、不想碰命令行，就用这个：一个 exe，双击打开开始检查，关掉窗口就彻底停止。

## 先分清三种运行方式

| 方式 | 什么时候在检查 | 适合 |
| --- | --- | --- |
| **桌面版 exe** | 窗口开着的时候 | 想自己在用电脑时才监控，关掉就完全不管 |
| 本机计划任务 | 开机登录后一直在后台跑 | 挂了不管，全天候盯着 |
| GitHub Actions | 不适用 | 境外 runner 访问不了 `jwxt:80`，只用来做公告广播 |

三者共用同一份代码与同一份 `config\.env`，可以换着用，但**别同时开**——
虽然代码里有单实例锁，同时开也容易搞混「到底谁在检查」。

## 拿到 exe

### 方式一：直接下载

仓库 `Releases` 里如果有 `法大成绩提醒.exe`，下载后跳到「第一次使用」。

### 方式二：自己打包（1 分钟）

需要本机有 Python 3 与依赖：

```powershell
pip install -r requirements.txt pyinstaller
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_exe.ps1
```

产物在 `dist\法大成绩提醒.exe`（约 18 MB，单文件，自带 Python 运行时）。
打包失败或者想看到报错，加 `-Console` 打一个带黑窗口的调试版：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_exe.ps1 -Console -Name 法大调试版
```

## 第一次使用

1. **把 exe 放到项目根目录**，和 `config\`、`state\` 同级。
   exe 读的是「它自己所在目录」下的配置，换个位置就会变成另一套配置。
2. 双击运行。第一次会弹出设置窗口，填：
   - 学号、智慧法大统一认证密码
   - 通知渠道（`dingtalk` / `feishu`，不想推送就选 `none`）
   - 机器人 Webhook 与加签密钥
   - 检查间隔（默认 10 分钟，3～120）
3. 点「保存并开始」——**立刻检查一次**，之后按间隔自动跑。

> 第一次运行只建立基线，不会把历史成绩一次性推给你。

## 日常怎么用

- **开着窗口 = 正在监测**。标题下方显示「● 监测中（每 10 分钟）」和上次检查结果。
- **关掉窗口 = 停止监测**，进程退出，不再有任何后台请求。
- 中途想停一下但保留窗口，点「暂停监测」；再点「继续监测」恢复。
- 「立即检查」随时手动跑一次，不影响原有节奏。
- 「打开日志」会打开 `logs\` 目录：`app.log` 是全程日志，`runs.jsonl` 是结构化运行记录。
- 窗口最小化不影响监测，**只有关闭窗口才会停**。

## 界面能看到什么

| 区域 | 内容 |
| --- | --- |
| 状态 | 监测中 / 已暂停 / 未配置；本次是「新增 N 门：xxx」还是「无新增（共 N 门）」 |
| 运行日志 | 登录、抓取、比对、推送的实时日志，保留最近 800 行 |
| 按钮 | 立即检查 / 暂停·继续 / 设置 / 打开日志 / 退出 |

## 常见问题

**双击没反应，或者闪一下就没了**
用 `-Console` 参数打个调试版（见上），双击后会留下黑窗口显示 Python 报错。
也可以用源码直接跑，报错更清楚：

```powershell
python app.py
```

崩溃信息还会写到 `logs\crash.log`。

**提示「用户名或密码错误」**
填的是**智慧法大统一认证**（`ca.cupl.edu.cn`）的密码，不是教务系统的本地密码。
先去 <https://ca.cupl.edu.cn> 用同一个密码登录一次试试。

**改了设置却不生效**
保存时会自动重启用监测线程；如果状态一直不变，关掉窗口重新打开即可。

**exe 被 Windows 或杀毒软件拦**
PyInstaller 打的单文件 exe 常被误报。可以改用源码运行（`python app.py`），
或者把 exe 加入信任列表。

**想彻底不留痕迹**
关掉窗口，删除 `logs\`、`state\grades.json` 与 `config\.env` 即可。
