# 桌面版 exe（打开就监测，关掉就停）

不想装 Python、不想碰命令行，就用这个：一个 exe，双击打开开始检查，关掉窗口就彻底停止。
通知走 **Windows 系统通知**，不用配钉钉、飞书机器人。

## 先分清三种运行方式

| 方式 | 什么时候在检查 | 通知方式 | 适合 |
| --- | --- | --- | --- |
| **桌面版 exe** | 窗口开着的时候 | 系统通知 + 强提醒 | 想自己在用电脑时才监控 |
| 本机计划任务 | 开机登录后一直在后台跑 | 系统通知 | 挂了不管，全天候盯着 |
| GitHub Actions | 不适用 | — | 境外 runner 访问不了 `jwxt:80`，只用来做公告广播 |

三者共用同一份代码与同一份 `config\.env`，可以换着用，但**别同时开**——
代码里有单实例锁，同时开也容易搞混「到底谁在检查」。

## 拿到 exe

### 方式一：直接下载

仓库 `Releases` 里如果有 `法大成绩提醒.exe`，下载后跳到「第一次使用」。

### 方式二：自己打包（1 分钟）

需要本机有 Python 3 与依赖：

```powershell
pip install -r requirements.txt pyinstaller
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_exe.ps1
```

产物在 `dist\法大成绩提醒.exe`（约 18 MB，单文件，自带 Python 运行时）。
打包失败或者想看到报错，加 `-Console` 打一个带黑窗口的调试版：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build_exe.ps1 -Console -Name 法大调试版
```

> 打包前请确认没有正在运行的旧 exe，否则 PyInstaller 无法覆盖文件。

## 第一次使用

1. **把 exe 放到项目根目录**，和 `config\`、`state\` 同级。
   exe 读的是「它自己所在目录」下的配置，换个位置就会变成另一套配置。
2. 双击运行。第一次会弹出设置窗口，填：
   - 学号、智慧法大统一认证密码
   - 通知方式：**电脑通知**（默认）或「不通知」
   - **强提醒**：勾上之后，新成绩会弹置顶窗口 + 闪烁任务栏 + 提示音，必须点「知道了」才消失
   - 检查间隔（默认 10 分钟，3～120）
3. 点「保存并开始」——**立刻检查一次**，之后按间隔自动跑。

> 第一次运行只建立基线，不会把历史成绩一次性推给你。

## 界面

窗口分两块，状态区在最上面。

### 状态区

| 显示 | 含义 |
| --- | --- |
| ● 监测中（每 10 分钟） | 定时线程在跑 |
| ● 已暂停 | 窗口还在，但不再检查 |
| 上次检查：18:46:12 · 新增 1 门：刑法学分论 | 最近一次结果 |
| 上次检查：18:46:12 · 无新增（共 42 门） | 没有新科目 |

### 「已出科目」页

- 列出**所有学期**已经出分的科目（不只是本学期），列：学期 / 科目 / 新增
- **本次新增的排在列表最上面**，黄色高亮并标记「新增」；其余按学期倒序
- 顶部有统计：`共 42 门 · 6 个学期 · 本次新增 1 门（置顶）`
- 程序刚启动、还没抓取时，先显示上次缓存（灰色），抓取成功后自动换成最新
- 只显示科目名，**不显示分数、学分、绩点**

### 「运行日志」页

登录、抓取、比对、推送的实时过程，保留最近 800 行。
同一份内容也会写到 `logs\app.log`，运行记录写到 `logs\runs.jsonl`。

## 通知怎么发

| 场景 | 会不会打扰你 |
| --- | --- |
| 有新科目成绩 | 弹系统通知；开了强提醒还会置顶弹窗 + 闪任务栏 + 提示音 |
| 登录失败 / 页面改版 | 只弹系统通知（不打断你），连续失败 2 次才发 |
| 首次建立基线 | 不通知 |

技术实现：调用 PowerShell 的 WinRT Toast API（`Windows.UI.Notifications`），
不装任何第三方库、不需要注册 AppID，所以通知标题会显示为 **Windows PowerShell**。
发不出去时只记日志、继续更新界面，不会让监控中断。

想彻底关掉通知：设置里把「通知方式」改成「不通知」，界面照常更新。

## 日常怎么用

- **开着窗口 = 正在监测**。关掉窗口 = 停止监测，进程退出，不再有任何后台请求。
- 中途想停一下但保留窗口，点「暂停监测」；再点「继续监测」恢复。
- 「立即检查」随时手动跑一次，不影响原有节奏（同时会刷新「已出科目」列表）。
- 「打开日志」打开 `logs\` 目录。
- 窗口最小化不影响监测，**只有关闭窗口才会停**。

## 常见问题

**双击没反应，或者闪一下就没了**
用 `-Console` 参数打个调试版（见上），双击后会留下黑窗口显示 Python 报错。
也可以用源码直接跑，报错更清楚：

```powershell
python app.py
```

崩溃信息还会写到 `logs\crash.log`。

**收不到系统通知**
先确认告警没被系统关掉：Windows 设置 → 系统 → 通知 → 找到 **Windows PowerShell**，允许通知并关闭「专注助手」。
也可以临时验证一次：

```powershell
python -c "import sys;sys.path.insert(0,'src');import notify;print(notify.toast('测试','通知通道自检'))"
```

输出 `True` 说明调用成功；仍看不到就是系统层面拦截了。
实在不行就把「强提醒」勾上——置顶窗口不依赖系统通知。

**提示「用户名或密码错误」**
填的是**智慧法大统一认证**（`ca.cupl.edu.cn`）的密码，不是教务系统的本地密码。
先去 <https://ca.cupl.edu.cn> 用同一个密码登录一次试试。

**「已出科目」是空的**
点「立即检查」。如果日志显示登录成功却仍为空，多半是页面改版，见 `docs/故障排查与回退.md`。

**改了设置却不生效**
保存时会自动重启用监测线程；如果状态一直不变，关掉窗口重新打开即可。

**exe 被 Windows 或杀毒软件拦**
PyInstaller 打的单文件 exe 常被误报。可以改用源码运行（`python app.py`），
或者把 exe 加入信任列表。

**想彻底不留痕迹**
关掉窗口，删除 `logs\`、`state\grades.json`、`state\grades_cache.json` 与 `config\.env` 即可。
