# 本机计划任务（GitHub Actions 的替代定时）

## 为什么要换

2026-11-06 在真实的 GitHub Actions runner 与本人电脑上各跑了一遍 `scripts/connectivity_check.py`，结果：

| 检查项 | GitHub Actions（境外） | 本机（国内） |
| --- | --- | --- |
| `jwxt.cupl.edu.cn:80` 登录页 | **FAIL（ConnectTimeout）** | PASS（200） |
| `tpass`(ca.cupl.edu.cn):443 | PASS | PASS |
| 取 RSA 公钥 | PASS | PASS |

结论：**不是 Actions 断网**——统一认证走 443 能通，教务系统走 80 全部超时，
说明境外云出口被目标侧按 IP / 地域拦掉了，换 runner、改超时时间都救不回来。

于是定时检查改在本机跑：

- `grade-check.yml` 的 `cron` 已注释掉，只保留手动 `workflow_dispatch`；
- 定时由 Windows 计划任务驱动 `src/scheduled_run.py`；
- 公告层 `announcement-watch.yml` 抓的是 `https://jwc.cupl.edu.cn`（443 的公开页），
  没有实测过境外可达性，暂时留在 Actions；如果它也天天红叉，把它的 `cron` 一起注释即可。

## 三步装好

前提：本机已装 Python 3（`python` 在 PATH 里），且已装依赖：

```powershell
pip install -r requirements.txt
```

### 1. 写配置

如果还没有 `config\.env`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local_setup.ps1
```

也可以直接用界面（`start_ui.bat`）或桌面版 exe 的设置窗口填，效果一样。
通知默认走**电脑通知**，不需要任何机器人；想更醒目就把强提醒打开。

### 2. 注册计划任务

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local_task.ps1 -Action install -IntervalMinutes 10
```

输出 `已注册计划任务「法大成绩提醒」，每 10 分钟检查一次` 即成功。
不需要管理员权限；任务注册在当前用户下，**只在你登录后才跑**。

### 3. 立刻跑一次，建立基线

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local_task.ps1 -Action run
```

第一次运行只建立基线，**不会**把历史成绩刷屏；之后有新科目才推送。

## 日常使用

| 想做 | 命令 |
| --- | --- |
| 看装没装、上次跑得怎样 | `.\scripts\local_task.ps1 -Action status` |
| 立刻跑一次 | `.\scripts\local_task.ps1 -Action run` |
| 改间隔（5～120 分钟） | `.\scripts\local_task.ps1 -Action install -IntervalMinutes 30` |
| 卸载 | `.\scripts\local_task.ps1 -Action remove` |

两种看运行结果的方式：

- **网页界面**（推荐）：`start_ui.bat` → 「运行记录」，计划任务跑过的每一次都在里面，
  和手动触发共用同一份 `logs\runs.jsonl`；
- **文本日志**：`logs\task-20261106.log`，按天一个文件，保留 14 天，超出自动清理。

## 实现细节

```
计划任务（每 10 分钟）
  → powershell -File scripts\run_monitor.ps1        # 选 Python、写日志、清旧日志
  → python src\scheduled_run.py                     # 跑一次 + 追加 logs\runs.jsonl
  → src\monitor.py 的登录 / 抓取 / 比对 / 推送逻辑   # 与 Actions 完全同一套代码
```

几个刻意的设计：

- **单实例锁**：`logs\.run.lock`。计划任务与界面监控同时开着也不会重复推送；
  进程被强杀留下的锁，10 分钟后自动视为残留并接管。
- **日志编码**：包装脚本强制 `PYTHONUTF8=1`，否则中文日志在 PowerShell 管道里会乱码。
- **补跑**：任务设置了 `StartWhenAvailable`，关机 / 休眠错过的检查会在开机后补一次。
- **多实例策略** `IgnoreNew`：上一轮还没跑完时，新的触发直接跳过，不会叠加。

## 常见问题

**任务状态显示 Ready 但一直不跑**
任务只在「当前用户已登录」时执行。锁屏可以，注销 / 关机不行。

**`找不到 python，请安装 Python 3 并加入 PATH`**
计划任务用的是系统 `python`，不是你终端里的 conda 环境。装一个官方 Python 并勾选
「Add python.exe to PATH」；或者在项目根目录建 `.venv`（包装脚本会优先用它）。

**日志里 `exit=1` 且写着 `缺少 CUPL_USERNAME / CUPL_PASSWORD`**
`config\.env` 没生成或被清掉了，回到「写配置」那一步。

**日志里 `ConnectTimeout` / `ConnectionError`**
本机网络到教务系统不通。先手动跑一次自检：

```powershell
python scripts\connectivity_check.py
```

本机全 PASS 才算环境正常。

**提示 `上一次运行还没结束，本次跳过`**
上一轮超过 10 分钟没结束（通常是网络卡住）。等下一轮，或删掉 `logs\.run.lock` 强制重来。

**想彻底停掉**
`.\scripts\local_task.ps1 -Action remove`，并删掉 `logs\.run.lock` 与 `state\grades.json`。
