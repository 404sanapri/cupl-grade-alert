# 合规与隐私

## 一、这个程序会碰哪些数据

| 数据 | 是否接触 | 存放位置 | 留存 |
| --- | --- | --- | --- |
| 学号 | 是 | GitHub Secrets / 本机 `.env` | 直到你删除 |
| 密码 | 是 | GitHub Secrets / 本机 `.env` | 直到你删除 |
| 登录 Cookie | 是（内存） | 不落盘 | 进程结束即消失 |
| 课程名 / 分数 / 绩点 | 是（内存） | 不落盘 | 仅用于判断是否出分；界面与推送都只显示科目名 |
| 比对用哈希键 | 是 | `state/grades.json` | 直到你清空 |

## 二、凭据怎么保护

- **云端**：GitHub Secrets 以加密形式存储，运行时注入环境变量。日志里不会回显，fork 出去的人默认也继承不到。
- **本机**：`config/.env` 已写入 `.gitignore`；`_load_dotenv` 只读取，不会回写。也可以把值放进 Windows 用户环境变量，完全不落文件。
- **代码**：仓库里没有任何真实凭据，`config/.env.example` 只有占位符。
- **日志**：`safe_summary()` 只输出 `user=240***`，密码、Webhook 的 token 段、Cookie 一律不打印。
- **推送内容**：只含课程名与检测时间；分数、学分、绩点不进入通知，也不含学号、姓名、密码。

## 三、快照为什么是安全的

`state/grades.json` 长这样：

```json
{
  "baseline_ready": true,
  "keys": ["0855d51c2d1d5163", "0b8bbdaa532c8a74"],
  "updated_at": "2026-11-06T16:46:02+08:00"
}
```

`key` 是 `SHA-1(学期|课程名)` 的前 16 位，**不可逆**。即使仓库是 Public，别人也无法从快照反推出你修了哪些课、考了多少分。

## 四、如何彻底删除

```powershell
python src\monitor.py --reset-state
```

然后：

1. 仓库 **Settings → Secrets → 删除 `CUPL_USERNAME` / `CUPL_PASSWORD`**；
2. **Actions → 成绩更新监控 → ⋯ → Disable workflow**；
3. 不需要的话，直接删除整个仓库；
4. 本机删掉 `config/.env`。

做完这四步，本地与云端都不再有任何残留。

## 五、使用边界

**允许**：

- 查询**你自己**的成绩并提醒自己；
- 把本项目分享给同学，让他们 fork 自己的副本。

**不允许**：

- 代查他人成绩，或收集他人账号密码；
- 把本项目改造成批量爬取、成绩排名抓取等用途；
- 任何商业用途；
- 高频轮询影响教务系统正常运行。

## 六、请尽快改密

如果你当前密码仍然等于学号（或其它弱口令），建议立即在 <https://ca.cupl.edu.cn> 修改。

改密后只需更新 `CUPL_PASSWORD` 这一个 Secret，其余不用动。
